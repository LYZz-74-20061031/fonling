# Fonling GLM 成本优先模型路由设计

日期：2026-08-23  
状态：用户已批准，等待实施计划  
范围：全局模型配置、GLM 免费/单次 Air 路由、DeepSeek 兼容保留、输入区模型与身份状态、消息模型来源

## 1. 目标

Fonling 默认使用智谱免费文本模型，避免普通剧情、摘要和记忆分析产生模型费用；只在用户明确操作时，针对一条新消息或最新一条 AI 回复调用 `glm-4.5-air`。现有 DeepSeek 能力保留为手动备用，但永不参与自动降级。

本设计必须保证：

- 日常默认路径不消耗 GLM-4.5-Air 资源包。
- 任何自动任务都不能调用 Air 或 DeepSeek。
- 任何付费或资源包调用都必须来自当次明确的用户操作。
- GLM、DeepSeek API Key 全局共享，不再属于单个智能体。
- 角色 JSON 不导出或导入 API Key。
- 角色、聊天、摘要、记忆和场景的现有行为保持兼容。
- 发送按钮统一为白底黑色图标。

## 2. 非目标

本阶段不实现：

- FreeLLMAPI、自托管模型代理或云端中转服务。
- Gemini、Groq、OpenRouter、Ollama 等其他供应商。
- 自定义 API Base URL 或任意模型名称输入。
- 温度、top_p、token 上限等高级参数面板。
- GLM 隐藏推理内容的展示或保存。
- 角色列表、角色快捷切换弹窗或多智能体同场发言。
- 对历史任意 AI 回复进行重新生成。
- 全局设置 JSON 导出。

## 3. 模型分工

### 3.1 默认免费路径

以下任务固定使用 `glm-4.7-flash`：

- 普通剧情回复。
- 自动摘要。
- 自动或手动记忆分析。

所有 GLM 请求显式传入：

```json
{
  "thinking": { "type": "disabled" }
}
```

应用不读取、不展示、不保存 `reasoning_content`。

### 3.2 单次 Air 路径

以下两种操作允许使用 `glm-4.5-air`：

1. 用户在输入区点击“深度思考（付费模型）”，然后发送下一条消息。
2. 用户对最新一条 AI 回复点击“重新深度思考”。

Air 同样关闭思考模式。界面中的“深度思考”是手动高质量模型入口名称，不代表启用 GLM 的 `thinking` 功能。

Air 不用于摘要、记忆分析、自动重试或任何后台任务。

### 3.3 DeepSeek

DeepSeek 保留为全局手动备用供应商：

- 默认不选中。
- 用户可在全局设置中主动将普通剧情供应商切换为 DeepSeek。
- 切换前提示其可能产生费用。
- GLM 失败时不得自动切换到 DeepSeek。
- 即使普通剧情手动选择 DeepSeek，摘要和记忆分析仍使用 `glm-4.7-flash`。
- 输入区的单次“深度思考”始终指向 `glm-4.5-air`。

## 4. 固定请求参数

第一版不提供高级参数 UI。

### 4.1 剧情回复

- 免费模型：`glm-4.7-flash`
- 单次模型：`glm-4.5-air`
- 流式输出：开启
- `thinking.type`：`disabled`
- `max_tokens`：4096
- `temperature`：0.9
- `top_p`：使用供应商默认值

### 4.2 自动摘要

- 模型：`glm-4.7-flash`
- 流式输出：关闭
- `thinking.type`：`disabled`
- `max_tokens`：1024
- 使用低随机性
- 摘要正文继续限制在约 1000 tokens

### 4.3 记忆分析

- 模型：`glm-4.7-flash`
- 流式输出：关闭
- `thinking.type`：`disabled`
- `max_tokens`：1400
- `temperature`：0.1
- `response_format`：JSON 对象

## 5. 全局模型配置

### 5.1 存储边界

新增独立的、带版本号的全局模型配置。它至少包含：

- 配置版本。
- 默认剧情供应商：GLM 或 DeepSeek。
- GLM API Key。
- DeepSeek API Key。
- 成本保护策略。
- 最近一次连接测试的结果和时间。

模型编码作为当前版本的受控常量，不由用户自由输入。

全局模型配置不得写入角色状态、角色设置快照或角色 JSON。

### 5.2 设置界面

现有设置抽屉顶部新增“模型服务（全局）”，并明确说明：

> 对所有智能体生效，不随角色 JSON 导入或导出。

GLM 区域包含：

- GLM API Key 密码输入框。
- 显示/隐藏按钮。
- 测试连接按钮。
- 未配置、连接成功、Key 无效、请求受限等状态。
- 默认免费模型只读展示：GLM-4.7-Flash。
- 单次模型只读展示：GLM-4.5-Air。
- “Air 仅由用户主动调用”的成本提示。

DeepSeek 放入默认折叠的“备用模型设置”，包含：

- DeepSeek API Key。
- 测试连接按钮。
- “不会自动调用”的提示。

默认剧情供应商选择包含：

- GLM-4.7-Flash（免费，推荐）。
- DeepSeek（可能产生费用）。

### 5.3 保存行为

- API Key 输入框失去焦点后自动保存。
- 保存失败时恢复修改前的状态和控件值。
- 测试连接不修改角色数据。
- 切换或删除智能体不修改全局配置。
- 清空聊天不修改全局配置。

## 6. 旧数据迁移与导入导出

### 6.1 旧 DeepSeek Key

旧角色数据的 `apiKey` 仅作为一次迁移来源：

- 如果全局 DeepSeek Key 为空，可从当前成功加载的旧角色复制一次。
- 如果全局 DeepSeek Key 已存在，旧角色 Key 不得覆盖它。
- 迁移失败不得破坏角色加载。

### 6.2 新角色导出

新版本角色 JSON：

- 不包含 GLM API Key。
- 不包含 DeepSeek API Key。
- 不包含默认供应商或全局成本策略。
- 保留消息的生成来源元数据。

### 6.3 角色导入

- 导入新版 JSON 不读取或修改全局模型配置。
- 导入旧版 JSON 时，角色数据正常迁移。
- 旧版 `apiKey` 仅在全局 DeepSeek Key 为空时可作为兼容迁移来源。
- 已有全局 Key 永不因导入角色而被覆盖。
- 无效导入必须让角色数据和全局配置都保持原样。

## 7. 输入区与身份显示

### 7.1 轻量状态栏

删除现有大块“当前身份：××”色块。输入框正上方保留一条轻量状态栏：

- 左侧：模型模式按钮。
- 右侧：角色主题色圆点和角色名称。

身份规则：

- 主控显示白色或中性灰色圆点和“主控”。
- 角色显示其现有主题色圆点和角色名。
- 长名称在可用宽度内截断，不挤压模型按钮。
- 第一版身份显示不是角色列表入口。

### 7.2 发送按钮

- 始终为白底黑色发送图标。
- 不随主控或角色主题色变化。
- 只表达发送、禁用和生成中状态。

### 7.3 单次 Air 按钮

默认文案：

> 深度思考（付费模型）

激活文案：

> 深度思考 · 付费 · 仅本条

激活状态使用独立的金色视觉，不改变身份圆点或发送按钮颜色。

## 8. 一次性 Air 状态机

### 8.1 激活

- 用户点击模型按钮后，状态变为“下一次剧情请求使用 Air”。
- 只在真正开始请求时捕获本次生成计划。
- 输入校验失败且请求未开始时，不产生 Air 调用。

### 8.2 消耗与恢复

- 新消息请求一旦开始，生成计划固定为 Air。
- 请求成功、HTTP 失败、网络失败、超时、取消或保存失败后，状态都恢复免费。
- 请求进行期间按钮不可重复操作。
- 切换智能体、切换角色身份或刷新页面时，尚未使用的 Air 状态取消。
- 摘要和记忆分析无法读取或继承一次性状态。

## 9. 重新深度思考

只有最新一条 AI 回复提供“重新深度思考”。

执行规则：

- 直接使用 `glm-4.5-air`，无需先激活输入区按钮。
- 旧回复在新回复完成并成功保存前保持不变。
- 新回复成功保存后，原子替换旧回复和相关生成来源。
- 请求失败、响应为空或保存失败时保留旧回复及其衍生数据。
- 完成后恢复免费状态。
- 更早的 AI 回复不提供该操作，防止破坏单线剧情后续内容。

## 10. 消息生成来源

每条新 AI 消息保存最小生成来源：

- 供应商。
- 实际模型。
- 免费或 Air 级别。
- 普通发送或重新生成。
- 生成时间。

显示规则：

- 免费回复不显示额外标签。
- Air 回复显示小型金色 `Air` 标签。
- 生成过程中可显示“Air 生成中”。
- 点击 Air 标签可查看供应商、模型和调用方式。
- 生成来源随角色 JSON 导出，但不包含凭据。

## 11. 错误处理与成本保护

### 11.1 免费剧情请求

仅以下错误自动使用同一免费模型重试一次：

- 网络错误。
- 429 限流。
- 服务器 5xx。

以下错误不自动重试：

- API Key 无效或缺失。
- 请求参数错误。
- 明确的模型或权限错误。

免费重试仍失败后：

- 保留用户消息。
- 提供“再次免费尝试”。
- 提供“深度思考本条”。
- 不自动调用 Air 或 DeepSeek。

### 11.2 Air 请求

- Air 永不自动重试。
- 失败后保留用户消息；重新生成场景保留原 AI 回复。
- 失败、超时或资源包不可用后恢复免费状态。
- 用户必须再次明确点击才能重新调用 Air。
- 余额不足、权限不足或资源包失效时显示明确提示。

### 11.3 后台任务

- 摘要与记忆分析只使用免费模型。
- 失败后不得调用 Air 或 DeepSeek。
- 记忆分析保持可重试状态。
- 摘要失败保留所有原始消息和旧摘要。
- 后台失败不阻塞继续聊天，避免连续阻断式弹窗。

## 12. 模块边界

实现时把新增职责从 `index.html` 拆分为小模块：

1. 全局模型配置：默认值、校验、原子保存和旧 Key 迁移。
2. 模型请求路由：为每次任务创建不可变生成计划，并选择供应商。
3. GLM 适配：请求参数、错误分类、SSE 与非流式响应解析。
4. DeepSeek 适配：保留现有行为并接入统一路由接口。
5. 一次性 Air 控制：激活、捕获、恢复和身份切换失效。
6. 模型 UI：全局设置、状态栏、Air 标签和失败操作。

现有聊天上下文、摘要、记忆分析和角色逻辑通过统一路由调用，不各自硬编码供应商 URL、Key 或模型名。

## 13. 测试策略

自动化测试至少覆盖：

- GLM 免费剧情、摘要和记忆请求体。
- Air 请求体及思考模式关闭。
- GLM SSE 分片、UTF-8 跨分片和结尾无换行数据。
- 非流式摘要与 JSON 记忆分析解析。
- 免费模型只对可重试错误自动重试一次。
- Key、参数和权限错误不重试。
- Air 在所有错误下都不自动重试。
- Air 一次性状态在成功、失败、超时、取消和保存失败后恢复。
- 切换智能体、角色身份和刷新初始化取消未使用状态。
- 摘要和记忆分析无法触发 Air。
- 重新深度思考成功时原子替换，失败时保留旧回复。
- Air 标签只出现在 Air 回复。
- 全局配置保存失败回滚。
- 旧 DeepSeek Key 一次迁移。
- 新角色 JSON 不包含 API Key。
- 旧 JSON 不覆盖已有全局 Key。
- 清空聊天、删除角色和角色导入不修改全局配置。
- 发送按钮为白底黑色，身份状态栏在手机宽度下不溢出。

真实接口验收只调用一次 `glm-4.7-flash`：

- API Key 仅通过临时运行环境或设置界面提供。
- 不写入代码、规格、测试、日志或 Git 文件。
- 使用极短提示和很小的输出上限。
- 明确关闭思考模式。
- 不调用 Air、DeepSeek、摘要或记忆分析。

## 14. 验收标准

- 未进行任何付费操作时，所有自动与手动默认请求都走 `glm-4.7-flash`。
- 只有两种明确操作可以调用 Air：下一条单次生成、最新回复“重新深度思考”。
- Air 请求结束后无条件恢复免费状态。
- 免费失败永不自动升级为 Air 或 DeepSeek。
- API Key 对所有智能体共享，但角色 JSON 中不存在 API Key。
- 角色切换继续正确显示主题色圆点和名称。
- 发送按钮始终白底黑图。
- 现有 234 项回归测试及新增模型测试全部通过。
- Chrome 手机尺寸下输入、切换身份、免费生成、单次 Air 和失败恢复均可用。
